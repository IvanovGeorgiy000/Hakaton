# СтройКонтроль — фронтенд прототипа

Интерфейс сервиса мониторинга строительных площадок по снимкам с камер
(ЛЦТ 2026, задача Департамента градостроительной политики г. Москвы, команда «Работяги»).

Только фронтенд с мок-данными: бэкенда и ML здесь нет. Все данные лежат в `src/data/`
и подменяются на реальные API без переделки экранов.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # сборка в dist/
```

## Роли

Экран входа: форма «логин + пароль» (логины стенда: `prorab`, `rukovoditel`, `inspektor`, `admin`, пароль любой)
и быстрый вход по роли одним нажатием. Роль запоминается в браузере.

Отдельная страница без входа — `/demo`: минимум по ТЗ на одном экране (снимок → техника → этап → отклонения).

| Роль | Что видит | Что может |
|---|---|---|
| **Прораб** | Только свой объект: «светофор», этап, отклонения, камеры, план | Ответить на отклонение: «Техника едет», «Подтверждаю проблему», «Это ошибка», «Устранено» |
| **Руководитель проекта** | Все объекты, лента отклонений, любой объект в деталях | Подтвердить / закрыть отклонение, проверить загруженное фото по правилам этапа |
| **Инспектор** | Журнал нарушений по всем объектам, отчёт за неделю | Выдать предписание, закрыть нарушение, выгрузить CSV |
| **Администратор** | Правила «этап → техника», камеры, сотрудники | Менять правила кнопками «+ / −», включать и выключать камеры |

## Что показывает интерфейс (по ТЗ)

- **Обнаружение техники** — рамки с типом и уверенностью на снимках (`CameraFrame`).
- **Сопоставление с графиком** — таблица «нужно по плану / видим на камерах» (`EquipmentCheck`)
  и календарный план с нужной техникой на каждом этапе (`StageTimeline`).
- **Выявление отклонений** — карточки с понятной формулировкой, снимками-доказательствами,
  блоком «Почему система так решила» (план → правило → снимки → вывод) и подсказкой «Что делать».
- **Методика** — правила в `src/data/rules.ts`: для каждого этапа обязательная техника с минимумом,
  допустимая и «лишняя», плюс число снимков подряд для подтверждения отклонения.

## Структура

```
src/
  data/         типы и мок-данные: техника, объекты, камеры, план, правила, снимки, отклонения, пользователи
  store/        контекст приложения: роль, статусы отклонений, редактируемые правила
  components/   CameraFrame, AlertCard, AlertDetail, EquipmentCheck, StageTimeline, CamerasGrid, ui/*
  pages/        экраны по ролям: foreman/, manager/, inspector/, admin/ + Login, MinimalDemo, Help
  lib/          утилиты (cn, форматирование дат по Москве, подписи статусов)
```

## Настоящие снимки

В `public/snapshots/` лежат 13 реальных фото стройплощадок с Wikimedia Commons (авторы и лицензии — в `public/snapshots/CREDITS.md`),
рамки техники размечены по ним вручную. Чтобы добавить свои: положите фото 16:9 в `public/snapshots/` и укажите `imageUrl: '/snapshots/имя.jpg'` у снимка в `src/data/snapshots.ts` —
кадр заменит схематичную сцену, рамки детекций лягут поверх.
