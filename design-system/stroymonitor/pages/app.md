# Override: рабочее приложение «СтройКонтроль» (приоритетнее MASTER.md)

MASTER.md сгенерирован как тёмная glass-тема — для прорабов на площадке она не подходит.
Фактическая система (источник истины — `frontend/src/index.css`):

- **Стиль:** светлая рабочая панель (data-dense dashboard, но с крупными элементами). Палитра «B2B navy + blue CTA».
- **Цвета:** фон `#F4F6F8`, карточки белые с рамкой `#DFE4EB` и тенью `--shadow-card`; акцент `#1D4ED8`;
  боковое меню `#0B1526`. Цвет несёт смысл только в статусах (ok / warn / danger / info) — без пастельных заливок блоков,
  статус показывается тонкой полосой слева, бейджем и цветом подписи.
- **Шрифт:** Inter Variable (self-hosted, `@fontsource-variable/inter`), база 16px, цифры `tabular-nums`, служебные номера — mono.
- **Скругления:** 8 / 10 / 14px. Тени только у карточек и всплывающих слоёв.
- **Каркас:** десктоп — тёмное боковое меню 256px + верхняя панель (дата, статус синхронизации, колокольчик);
  телефон — верхняя панель + нижняя навигация с подписями.
- **Простота для неподготовленных пользователей (не ломать):** тач-цели ≥ 44px, одна главная кнопка на экран,
  простые слова вместо терминов, «светофор» состояния объекта, подтверждение каждого действия всплывающим сообщением,
  быстрый вход по роли без ввода текста.
- **Анимации:** только framer-motion, короткие (≤ 250 мс), `MotionConfig reducedMotion="user"`.
- **Кадры камер:** `Snapshot.imageUrl` — настоящий снимок; без него рисуется схема с зерном, виньеткой и экранными надписями.
